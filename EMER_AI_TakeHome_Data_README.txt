EMER AI ENGINEER TAKE-HOME DATA PACK

Files:
- EMER_AI_TakeHome_Knowledge_Corpus.jsonl: JSONL knowledge corpus with 35 records.
- EMER_AI_TakeHome_Evaluation_Questions.txt: Sample questions for testing retrieval and answer grounding.

IMPORTANT:
- This dataset is entirely synthetic and was created only for an engineering interview.
- It contains no real patient data and should not be used for medical care.
- Each JSONL row includes doc_id, title, category, version, effective_date, authority, and text.
- The corpus intentionally includes a superseded and a current policy so version-aware retrieval can be demonstrated.
- Candidates are free to transform or index the data however they choose, but should preserve source metadata for citations/provenance.
