# Intelligence release checkpoint — September 12, 2026

The runtime uses Gemini3.8Flash Low for generation, planning and conversation references, and distinct GPT5.5 Low for evidence assessment and final semantic verification. Direct OpenAI Live remains the media transport; its factual answers use this same backend. High reasoning was removed after planning alone reached133.8seconds and an end-to-end case245.9seconds. The measured contextual follow-up improved from113.2 to20.9seconds using Low reasoning; provider latency varies.

Source-aware stable chunks/offsets, immutable FTS/vector indexes, per-question-part hybrid retrieval, generic source applicability/supersession, controlled input/evidence budgets, bounded recovery, structured conversation references and independently checked exact original citations remain enabled. Complete answer repairs are fully rechecked instead of applying locked-item patches. Compact reusable vectors and bounded caches reduce memory overhead. Model input is bounded independently of retrieved evidence. No model-controlled retrieval tools were added; backend orchestration remains deterministic.

This is a release checkpoint, not a claim that all quality gates passed. Faster GPT4.1Mini and GPT5.4Mini verifier experiments were rejected after missing-part/coverage failures. GPT5.5 is retained. Low and Medium generation trials still failed some compound/status cases after bounded repair, including unnecessary workflow qualifications and omitted requested source context. These fail closed rather than publishing rejected content. Historical76/80 fact coverage is not a final score; the required full-fact and fresh-case gates remain open. Exact citation validity does not prove completeness. Physical hosted voice acceptance remains separate.
