# Birthday Traffic homepage assets

Source: https://birthdaytraffic.com/ — inspected and retrieved September 12, 2026 at the user's explicit request to reproduce its interactive homepage disco.

The disco photograph, forward/reverse packed-alpha rotation videos, outline, light samples and animated fallback are the original site assets, unchanged. The site's motion motor and WebGL compositor are retained. The controller and confetti code are adapted to local asset paths and instance-scoped cleanup. Homepage orchestration copies the original spin/celebration timings and feedback tones; unrelated birthday data, tracking, forms and game code are excluded. Upstream code/artwork did not declare a license in the inspected files; no ownership or upstream endorsement is claimed.

The identical jazz recording is Tom Kincaid / VOLE.wtf, CC0, with the upstream license retained in `audio/LICENSE.md`. Loop endpoints 0.65–25.95 s and master/music gain 0.14 × 1.8 match the reference. Effects stop when leaving the homepage, starting Live, or hiding the document. Initial audio waits for a disco/sound gesture.

CSS reproduces the reference's responsive ball dimensions, centered placement, gap, and Inter heading proportions, using the app's current light/dark colors. Audio controls sit beside the existing appearance control. Both supplied corpus files remain outside this asset directory and are unmodified.
